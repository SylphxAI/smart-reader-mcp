# Prism — positioning

## One-liner

**Prism**: Local media sniff + route — local-first, fast, light, powerful.

## Why agents use this

One call sniffs format and routes to the right sibling product contract with provenance — composition without monorepo.

## Surfaces

| Surface | Role |
| --- | --- |
| MCP | Agent tools over stdio |
| CLI | Human/scriptable brand bin |
| SDK | Programmatic library for apps and internal dogfood |

## Primary tools

- `read_media`
- `sniff_format`
- `resolve_media_path`
