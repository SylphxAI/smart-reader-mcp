# Prism — competitive positioning

## Job

Local media sniff + route

## Wedge

One call sniffs format and routes to the right sibling product contract with provenance — composition without monorepo.

## Local-first

Local sniff/route; delegates to installed sibling engines/contracts.

## Peer anchors (learn; do not clone)

| Peer | Gap we exploit |
| --- | --- |
| Manual multi-server MCP configs | Agent must know format and pick PDF vs image vs video server |
| Universal filesystem readers | Bytes only; no media-type routing with provenance |

## Non-goals

- Becoming a cloud SaaS wrapper as the default path
- Multi-product monorepo for star aggregation
- Generative summaries as the sole evidence authority
